# なぜ登録したか

* 自分語りがしたく
* 吐き出したく
* 我慢できず
* 吐瀉物を集約する場を設けて汚染地区を限定したく
* メタ認知したく

なぜ自分語りしたいか。それは知らん。自分でも分からんが、言わずにはおれん事がままある。それがすべての元凶だ。私が悪い。

リアルの対面で自分語りなどしようものなら万人に疎まれ排除される。私は別に迷惑を掛けたい訳でも嫌がらせしたい訳でもない。言わずにはおれん衝動を発散したいだけだ。故に自分語りをする場は選ばねばならん。

noteでもしばしば気持ち悪いと言われるのが自分語りだ。嫌がられる事を知って尚、こうしてそれをしようとする私は受け入れてはならない排除すべき害悪である。

だがそれはあくまで社会の評価であって、私の動機ではない。それを理解して尚それでもやろうとする動機こそ、ここで話すべき内容だ。

一言で言えば、言いたいから言う。ただそれだけの話だ。それだとここで終わってしまうので、もう少し詳細に述べようと思う。

私は既にnoteではなくブログをしていたが、やってみた事の記録を中心にしていたはずなのに、いつの間にか感想や思想など自分語りが混じりグチャグチャになってしまった。

いかん。このままでは何が何だか分からなくなる。もう手遅れだったが、済んでしまった事は仕方ない。せめてこれから先は、なるだけ報告と思想の混在を減らしたい。

だがそれは難しい。何かをやってみてその経緯や手順を記録する事の中には、自分自身の感想や思想、思索なども含んでいる。行為と思想は密接に関わっており、無関係なものとして分離できるものではない。

それをせずにはいられなかった行為がある時、必ずやそれをせずには居られなかった想いがある。それを語らずには居られない。その程度の強い想いがなければ、そもそも行動していなかったのだから当然だ。故に行為と思想は不可分である。

関係あるのに関係ない、あるいはそんな行為または思想など無かったものとして別々に扱うのは事実と異なる虚偽である。偽物は要らない。それではやる意味がない。事実こそが正しく、正しさこそが私の求めるものなのだから。

かといってそれらを混在させると何が何だか分からなくなる。話の要点がボヤケて何を言っているのか曖昧になり意味不明になる。

そこで私は考えた。とりあえず妥協して分離しよう。このまま手を止めて何もしないより、例え不完全でも偽物でも、分離して記述することを試みようと。だがいずれ精度を高めるために、どこでどう妥協したのかは明確にしておきたい。故に分析は不可欠だ。

問題の原因は何か。誰でも再現可能な手順と、私個人専用の思想という相容れぬものを同居させた事が問題だ。ではどう解決するか。これらを分離することで各自が何であるか伝わるようになるはず。

だが私の思想にはまとまりがない。ならばそれを、まとまりのない感想や思想としてまとめれば良い。矛盾しているが、少なくともこれで再現可能な手順をブログに、まとまりのない思想をnoteに分離することが可能になるはずだ。

私のnoteは、とりとめもない、まとまりもない、けれど言わずにはいられない、吐き出さずにはおれない支離滅裂な想いを吐き出す場とする。すなわち自分語りの場としてnoteを使う。

SNSでは字数が足りない。見給え、この長文を。たかが説明するだけでこの文字数だ。140字では足りん。そもそもSNSは他人の言説や感情に同調させられ扇動されるような見せ方をしている。私がしたい事は自分語りであって扇動され操られる事ではない。だから私には吐き出す場が必要だった。そしてnoteを選んだ。

これは実験だ。どうなるか分からない。飽きて投げ出すかもしれない。続いたらゴミ駄文が累積する事になる。どのみち明るい未来とは思えない。しかし吐き出すことを我慢できなかったから登録した。

# なぜ今まで登録しなかったか

迷惑だから。

noteの存在は昔から知っていた。使い分けについて考察した事もあった。しかしそれでも、まとまりのない、誰の役にも立たない駄文を書き連ねてやろうとは思えなかった。だから今まで登録しなかった。

ネットという公共の場に公開すべきは他者にとって役に立つ情報であるべきだ。決して自分語りをして利己を発揮する場であってはならない。それは自分の場ですべき事であって公共の場ですべき事ではない。

現に他の人々が書く記事は誰かの役に立つ事で満ちている。あるいはそれを口実に利益を得ようと目論んでいる記事だ。それが公共の場で行うべき社会活動である。彼らは正しい。

ところが私のしようとしていることは自己完結する自分語りである。それは誰の役にも立たないし経済活動にも成り得ない。そんな事を公共の場や市場でやるのは間違っている。私は誤りだ。

なぜ壁に向かって話さないのか。なぜチラシの裏に書かないのか。なぜ自分だけが読める日記に書かないのか。なぜわざわざ他人の目に触れるネットで自分語りを公開するのか。

誰かに見られることを意識することで自分を客観視できるから。そうすることでしか見えない自分を見たいから。あわよくば私の間違いや気づかぬ点を指摘してもらえるかもしれないから。

つまり私は他人の目を利用することで自己分析を捗らせたいという下心、利己がある。これは私一人でチラ裏に書いて読むだけでは実現できない。だからわざわざ公開するのだ。

どうせ自分しか読んでいないのだから。そう思えるからこそ書ける事がある。同様に、世界中の人々に読まれてしまいうるのだから。そう思えるからこそ書けない事がある。

何でも書けてしまうと、何をなぜ書けないと思うのか。そう思う自分の思想を自覚する機会が得られない。それでは私は永遠にそんな自分の一面を知らないまま死ぬだろう。私の事なのに私が知らないまま死ぬなど許せない。私は私の全てを知りたい。死ぬまでの間にできるだけ多くの私を知っておきたい。

公開することは書ける内容を減らすだろう。では、世界中の人々に対して、私は何をどこまで書ける？　私はそれを知らない。試した事はあるが、試していない事もある。まだ足りない。少なくともそれを主目的にした事はないのだから多くの余地がある。

私は私を知りたい。でも対面して他人と関わりたくはない。他人と関わらないまま、それでいて他人と関わる事でしか知れない自分を知るためにはどうしたらいい？　そんな矛盾をある程度実現する方法が、ネットという疎遠な関わり方である。

むろんネットはネットで知れる事が限定的になる。だが冒頭で述べたように、リアルのほうがもっとできない事が多い。自分語りそれ自体が嫌われる。始まりからして躓く。

ネットでさえも自分語りが嫌われる事は同じだが、一方的に語る分には構わない。相手の時間を強制的に奪う事にはならないからだ。読みたくなければ読まなければいい。その意思決定権は相手にある。それがそのまま、私が自分語りをして良い免罪符にもなりうる。ここがリアルとネットの違う所だ。

密な関係だからできる事もあれば、疎遠だからこそできる事もある。その違いを理解し活用すればいい。

厄介なのはコメント返しだ。果たしてどういうスタンスにすべきか。これは別の記事にしてよく考える必要がある。少なくとも私がどういう姿勢でいくか、それに沿うようなnoteの設定が可能か。考察と調査を進める必要がある。これは今後の課題だ。

どこまでいっても私の利己でしかない。誰かの役に立つものではない身勝手な事を公共の場でやるという罪を犯す。そうなれば私はもう私を罪人としか思えない。例え法律が許しても私の基準では罪人だ。私は私の思う罪を犯したくなくて、今まで登録することを避けていた。それが今まで登録しなかった理由である。
